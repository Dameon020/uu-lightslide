## 本次更新

- 主面板新增 **反向滚动：上下 / 左右**，两轴独立控制，选择自动保存，默认均关闭。
- **原速（100%）也支持反向**。恢复速度不会重置方向，需要完全恢复时关闭两个反向选项或退出应用。
- 修复 **Shift＋普通鼠标滚轮**：兼容模式下可以横向减速，并由「左右」选项控制反向；「上下」选项不会干扰这种横向操作。
- 保留原有速度、模式与自启动选择。自动模式只处理已识别的 UU 输入，兼容模式也会调整本机滚动。

## 下载与安装

普通用户下载 **UU-LightSlide-v0.5.0-universal.dmg**，打开后把 **UU轻滑.app** 拖入 **Applications（应用程序）**，再从应用程序启动，按提示开启辅助功能权限。安装在被远控的 Mac 上，手机和 iPad 无需额外安装。

升级前退出正在运行的旧版，再替换应用。需要 **macOS 13+**；同一安装包包含 Apple Silicon 和 Intel 架构。App ZIP 是备用包装，源码 ZIP 供开发者使用，校验和见 SHA256SUMS.txt。

**社区版未经过 Apple 公证。** 首次打开如被系统拦截，请确认来源可信后按 [Apple 官方说明](https://support.apple.com/102445) 操作。升级后如果辅助功能权限失效，可移除旧条目再添加当前应用。
