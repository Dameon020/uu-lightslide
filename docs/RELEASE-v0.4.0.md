# UU 轻滑 v0.4.0 · 调好速度，安心阅读

手机或 iPad 用 UU 远控 Mac，滚动条稍微一动就翻过头？UU 轻滑继续沿用 UU 自带的滚动工具条，把滚动速度调到适合阅读的程度。

这一版把操作收到了一个小面板里：**低于 100% 就减速，选原速就恢复。**

## 本次更新

- 主界面只保留速度、带刻度和吸附的滑块，以及 **5% / 10% / 25% / 原速** 四个快捷档位。事件计数、诊断、自启动和高级选项收进「⋯」。
- 点「原速」恢复正常速度，再点一次回到上次慢速；支持 **⌥ Option + 点击菜单栏图标** 切换。
- 兼容模式开启时，标题旁始终显示「兼容」；点击标签即可回到自动识别，重启保留选择。**兼容模式也会减慢本机鼠标。**
- 检测到 UU 连接信号且持续收到未标记滚动时，按需建议兼容模式，不自动改变模式，也不把未标记输入直接断定为 UU 输入。
- 未授权时禁用速度控件；授权后自动重新建立监听。新用户可通过三步引导确认滚动是否识别成功。
- 保留已保存的速度（包括 50% 等自定义值）、模式与自启动选择。旧版本只在内存中启用的兼容模式无法恢复，需重新选择一次。

## 下载与安装

**普通用户下载 `UU-LightSlide-v0.4.0-universal.dmg` 即可。**

1. 在被远控的 Mac 上打开 DMG，将 **UU轻滑.app** 拖入 **Applications（应用程序）**。
2. 推出安装磁盘，从“应用程序”打开 UU轻滑。
3. 按首次引导开启 **系统设置 → 隐私与安全性 → 辅助功能 → UU轻滑**。
4. 选一个速度，用手机/iPad 的 UU 滚动工具条试滚动。手机和 iPad 无需另装插件。

适用于 **macOS 13+**，安装包同时包含 Apple Silicon 与 Intel 架构。ZIP 是相同应用的备用包装；源码 ZIP 供开发者使用。校验和见 `SHA256SUMS.txt`。

**这是未经过 Apple 公证的社区版。** 首次打开可能被系统拦截；确认来源可信后，按 [Apple 官方说明](https://support.apple.com/102445) 在“隐私与安全性”中处理。升级后如果权限失效，可在辅助功能列表移除旧条目，再添加当前应用；不要关闭整个系统的安全保护。
