UU 轻滑

保留手机／iPad 上 UU 自带的滚动工具条，让 Mac 页面移动更慢、更可控。独立开源工具，非网易官方产品。

安装与授权

  1. 从 DMG 将 UU轻滑.app 拖入“应用程序”，推出 DMG 后启动。
  2. 当前社区包未经过 Apple 公证。若被 macOS 阻止，在确认来源可信后，按照 Apple 官方说明，到系统设置 → 隐私与安全性选择“仍要打开”。不要关闭系统安全保护。
  3. 点击菜单栏上下箭头图标，选择“授权辅助功能”，在系统设置 → 隐私与安全性 → 辅助功能中允许 UU轻滑。授权后会自动重新创建滚动监听，无需重启。
  4. 用手机/iPad的UU连接这台Mac，继续使用UU滚动工具条。默认速度为原来的10%。

日常调速

点击菜单栏图标旁的百分比，拖动滑块选择1%–100%，或选5%、10%、25%和原速。数值越小越慢，选择会被记住。

快速翻页时点原速，再点一次恢复上次速度；按住⌥点菜单栏图标也能切换。该功能不会直接跳到文档首尾。

滚动方向

主面板“反向滚动”中的“上下”“左右”可分别开启，关闭时沿用输入方向。选择会自动保存。原速只恢复速度，方向设置仍然有效；如需完全恢复，关闭两个反向选项并选原速，或退出应用。

自动模式

只处理能识别为UU组件发出的滚动事件。无需每次连接手动开启，普通本机鼠标输入保持原样。“等待UU滚动”只在首次引导中显示，识别到UU滚动后引导自动结束。Ctrl、Command或Option配合滚轮的动作保持原样。

没有减速时

可在“更多 → 诊断信息”查看计数。“更多 → 高级设置”可启用兼容模式，此模式也影响本机并跨启动保存。标题旁会一直显示“兼容”，点一下恢复自动。只有UU连接信号有效且持续无法识别滚动来源时，主面板才建议切换；不会自行开启兼容。

个别软件会按页/行吸附，尚未保证所有软件兼容。Apple Silicon已有真实远控反馈；Intel已经交叉编译，尚未实机验证。

隐私、启动与卸载

只订阅滚轮事件，不监听键盘文本、不读取文档或UU账号、不联网。首次运行尝试注册登录启动，可在更多菜单取消“登录Mac时自动启动”。卸载前取消自动启动、退出应用，再删除应用并从辅助功能列表移除。
