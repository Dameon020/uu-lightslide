## UU 轻滑 v0.3.0

手机或 iPad 通过 UU 远控 Mac 时，页面一滑就翻过头？UU 轻滑让你继续使用原来的滚动工具条，把速度调到适合阅读的节奏。

### 下载哪个文件？

**普通用户下载 `UU-LightSlide-v0.3.0-universal.dmg` 即可。** 打开后将 UU轻滑.app 拖入 Applications，推出安装磁盘，再从“应用程序”启动。

- DMG：推荐安装包。
- `.app.zip`：备用应用压缩包。
- `-source.zip`：完整源码、MIT许可证和构建文档。
- `SHA256SUMS.txt`：以上附件的校验值。

### 这一版有什么

- 自动识别 UU 滚动输入，默认降到原速的10%。
- 1%–100%可调，记住你选的速度。
- “原速30秒”快速翻页，到时自动恢复慢速。
- 菜单栏常驻，支持登录启动。
- 自动模式让普通本机鼠标输入保持原样。
- 不联网、不收集遥测、不读取网页或文档内容。

### 首次安装请留意

**需要 macOS 13+；这是未经过 Apple 公证的社区版。** 首次打开可能被系统阻止，请在确认来源可信后，按 [Apple 官方说明](https://support.apple.com/102445) 到“系统设置 → 隐私与安全性 → 仍要打开”确认。随后还需要为 UU轻滑 授予辅助功能权限。

包含 Apple Silicon 和 Intel 架构。Apple Silicon 已有真实远控使用反馈；Intel 已编译，尚未实机验证。个别软件按行/页滚动，实际效果可能不同。
