# 工作原理

UU 轻滑使用原生 Swift / AppKit，在 macOS 菜单栏运行。

## 事件处理

1. 通过 CoreGraphics event tap 只订阅 `scrollWheel` 事件。
2. 读取 `eventSourceUnixProcessID`，解析进程路径，判断是否来自 UURemote.app 内的已知组件。
3. 在自动模式下，仅对可识别的 UU 来源事件应用用户选择的比例；其他来源原样通过。
4. 优先读取像素移动量，按比例缩小；保留不足一像素的余量，避免极慢速时小幅输入全部被取整丢弃。
5. 将结果写回原事件，保留定位、修饰键、来源、时间及滚动阶段等信息。

方向改变、目标切换或暂停后会清空余量。Ctrl、Command、Option配合滚轮的操作不减速。原速与上次慢速由同一份速度偏好来回切换，无倒计时。

## 自动模式的含义

工具根据事件来源工作，不读取UU账号、设备列表或连接日志，也不将“UU程序正在运行”当成有人连接。因此，它能在输入到达时自动生效，但不会显示可靠的远程会话在线状态。

UU版本或输入路径若不保留来源标记，自动模式无法将它与其他系统输入区分。这时保持原样放行；用户可以显式开启兼容模式，接受全部滚动一起减速。兼容模式持久化，主面板一直显示可点击的兼容标签。

## 数据与权限

辅助功能权限用于系统输入事件处理。工具不监听键盘文本，不读取屏幕或文档，不联网。偏好通过本机UserDefaults保存；诊断计数只在更多菜单中显示。

## 验证范围

已进行合成事件/算法检查，覆盖比例、余量、反向/目标切换、来源路径、模式、组合键、原速往返、偏好迁移、对数刻度吸附和识别提示及阶段保留。已有Apple Silicon真实手机/iPad远控使用反馈。

Universal2包含arm64与x86_64，但Intel尚未实机验证。目标应用的按行/页吸附行为可能影响最终视觉效果，不能保证所有软件像素级连续滚动。


## 识别提示与授权恢复

连接证据只来自UU服务进程持有的活动 `PreventUserIdleDisplaySleep` 断言，名称限于已知的两种。程序常驻的 `PreventUserIdleSystemSleep`、`UserIsActive` 和未知/过期采样都不能触发提示。IOKit查询在后台队列运行，结果仅用于提示，不作为自动减速的必要条件。

只有自动模式、速度低于100%、权限与监听正常，连接证据持续至少2秒，且12秒窗口内有至少8次未标记的有效滚动、跨度至少3秒、近期没有成功识别UU输入，才提示“没识别到 UU 的滚动？”；不会自动开启兼容模式。来源未标记也可能是本机输入，因此这是条件性建议，不是失败诊断。连接信号读取失败时保持安静，仍可手动切换兼容模式。

辅助功能每秒检查。未授权时禁用速度控件并停止tap；授权恢复或tap不可用时先清理再重建，不要求用户重启。首次引导仅对新安装自动展示，老用户可在更多菜单重新打开。
